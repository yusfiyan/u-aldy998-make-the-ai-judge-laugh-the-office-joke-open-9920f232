One single-line office joke for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. The program writes the joke to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`), and an AI judge compares it head to head against the other entries. The joke: an out-of-office that says "on annual leave", a calendar that invites you to a meeting anyway, and HR still wanting a status update from a ghost.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
